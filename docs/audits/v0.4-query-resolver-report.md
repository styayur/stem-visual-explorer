## Architecture

Raw Query → Normalizer → Lexical / Symbolic Parser → Candidate Generator →
Deterministic Ranker / span constraints → Ambiguity / Abstention → Canonical
Concept IDs → ConceptSession → Workbench.

[Resolver architecture](../query-resolver-v2.md) documents normalization,
lexicon provenance, script handling, abbreviations, typo bounds, finite symbol
and formula grammar, integer scoring, margins, composition, parity, security
and extension. The 494-concept ontology, its aliases and provider indexes are
unchanged. One resolver supplies the compatibility API, Search and ranked
Universal Search. Ambiguous queries need explicit localized choice; unknown
queries remain ordinary resource searches.
